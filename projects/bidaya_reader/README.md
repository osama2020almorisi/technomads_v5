# 📖 البداية والنهاية — قارئ HTML

قارئ محلي لكتاب "البداية والنهاية" لابن كثير — يعمل بدون إنترنت.

## المزايا
- ✅ HTML/CSS/JS فقط — بدون Python
- ✅ يخزّن الكتاب في المتصفح (IndexedDB)
- ✅ بحث متقدم (بسيط / دقيق / جذور)
- ✅ علامات + ملاحظات + سجل قراءة
- ✅ 4 أحجام خط + 3 خطوط + 3 خلفيات
- ✅ PWA — يُثبّت على الجوال

## التشغيل
1. افتح `index.html` في المتصفح
2. اضغط "استيراد الكتاب"
3. اختر ملف `bidaya_full.json`
4. ابدأ القراءة

## النشر على الإنترنت
- ارفع المجلد إلى **Netlify** أو **Vercel**
- يعمل مجانًا

# Bidaya Reader Pro

قارئ ومحرر مكتبة عربية يعمل محليًا باستخدام HTML وCSS وJavaScript وIndexedDB.

## التشغيل
- افتح `index.html` مباشرة للوظائف الأساسية. بعض إمكانات PWA وService Worker تتطلب استضافة HTTPS أو localhost.
- للنشر: ارفع المجلد كما هو إلى GitHub Pages أو Netlify أو Vercel.
- البيانات تحفظ في IndexedDB داخل المتصفح؛ صدّر نسخة JSON للاحتفاظ بنسخة احتياطية.

## الميزات
- مكتبة متعددة الكتب، استيراد JSON/TXT/HTML، واستيراد DOCX/EPUB عبر مكتبات CDN عند توفرها.
- قارئ RTL، سجل قراءة، علامات، محرر محتوى، بحث عربي، وتصدير JSON/HTML/TXT.
- واجهة متجاوبة ومظهر ليلي/نهاري وإعدادات أساسية.

## البنية
الصفحات مستقلة في الجذر، التنسيقات في `css/`، والوحدات البرمجية في `js/`.

## حدود الصيغ
الاستيراد والتصدير المتقدم لبعض صيغ EPUB/PDF/DOCX يعتمد على مكتبات خارجية. تشغيل `index.html` مباشرة قد يمنع المتصفح بعض ميزات الوحدات أو التخزين في بعض البيئات؛ استخدم استضافة ثابتة أو خادمًا محليًا عند الحاجة. لا تُرفع الكتب إلى أي خادم من التطبيق.

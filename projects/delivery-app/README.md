# 🚚 TechNomads Delivery Management System

نظام إدارة توصيل متكامل (Delivery Management System) مبني بتقنيات الويب الحديثة.

## 📋 المتطلبات

- متصفح حديث (Chrome, Firefox, Safari, Edge)
- خادم ويب محلي (مثل Live Server) لتشغيل الملفات

## 🚀 التشغيل السريع

```bash
# 1. استنساخ أو فك ضغط المشروع
cd technomads-delivery-system

# 2. تشغيل لوحة تحكم المشرف
open admin-dashboard/pages/dashboard.html

# 3. تشغيل تطبيق السائق (وضع الهاتف)
open driver-app/pages/dashboard.html

# 4. تشغيل تطبيق العميل (وضع الهاتف)
open customer-app/pages/home.html

# 5. تشغيل واجهة الويب
open customer-web/pages/index.html
```

## ✨ المميزات المنفذة

### لوحة تحكم المشرف
- ✅ إحصائيات حية مع رسوم بيانية
- ✅ إدارة الطلبات (إنشاء، تعديل، حذف، تتبع)
- ✅ إدارة السائقين وتتبع مواقعهم
- ✅ إدارة العملاء وقاعدة البيانات
- ✅ تقارير يومية/شهرية/سنوية
- ✅ خريطة تفاعلية للتتبع المباشر
- ✅ نموذج إنشاء طلب سريع
- ✅ تصميم RTL كامل للعربية

### تطبيق السائق
- ✅ تبديل الحالة (متاح/غير متاح)
- ✅ استلام الطلبات مع نموذج قبول
- ✅ تحديث حالة الطلب (4 مراحل)
- ✅ تتبع GPS محاكى
- ✅ إتصال مباشر بالعميل
- ✅ سجل الطلبات والإيرادات
- ✅ إشعارات فورية

### تطبيق العميل
- ✅ إنشاء طلب توصيل جديد
- ✅ تتبع مباشر مع شريط التقدم
- ✅ معلومات السائق والتواصل
- ✅ خريطة تفاعلية
- ✅ تقدير السعر التلقائي
- ✅ عروض ونقاط ولاء
- ✅ سجل الطلبات
- ✅ دعم متعدد المدن

### واجهة الويب
- ✅ صفحة تسويق احترافية
- ✅ نموذج تتبع الطلب
- ✅ عرض حالة الطلب بالتفصيل
- ✅ معلومات السائق
- ✅ تصميم متجاوب بالكامل

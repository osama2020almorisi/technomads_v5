# League App — مركز إدارة الدوري

تطبيق ويب متعدد الصفحات (MPA) عربي RTL لإدارة دوري رياضي محليًا باستخدام HTML وCSS وJavaScript فقط، بلا مكتبات خارجية أو CDN.

## المحتويات
- 10 صفحات مستقلة، والتنقل بروابط HTML عادية.
- 12 فريقًا و240 لاعبًا و30 مباراة في بيانات البداية.
- حساب ترتيب الفرق، البحث والفلترة، تفاصيل المباريات والفرق، الإحصائيات والانضباط.
- LocalStorage مع نسخة IndexedDB احتياطية، واستيراد وتصدير JSON.
- لوحة إدارة PIN افتراضي 1234، إدارة فرق ولاعبين ومباريات وتسجيل أحداث وسجل تدقيق.
- PWA وService Worker وواجهة متجاوبة مع وضع داكن/فاتح.

## التشغيل
افتح `index.html` لعرض الواجهة الأساسية. بسبب سياسات المتصفح، بعض الميزات مثل `fetch` لبيانات JSON وService Worker وPWA لا تعمل من `file://`. لتفعيل جميع الميزات، شغّل مجلد المشروع عبر خادم محلي أو استضفه على HTTPS. لا توجد حاجة إلى تثبيت مكتبات.

## تخزين البيانات
يتم حفظ التغييرات محليًا في المتصفح على الجهاز نفسه. امسح البيانات من صفحة الإعدادات فقط بعد تصدير نسخة احتياطية. وضع PIN حماية محلية بسيطة وليس نظام مصادقة آمنًا ضد مستخدم لديه وصول إلى ملفات المشروع أو أدوات المطور.

## الاستيراد والتصدير
من الإعدادات اختر ملف JSON مطابقًا لـ `data/schema.json`، وسيتم التحقق من الحقول الأساسية والعلاقات بين الفرق واللاعبين والمباريات قبل استبدال البيانات. زر PDF يفتح نافذة الطباعة؛ اختر «حفظ بتنسيق PDF».

## ملاحظات
- بيانات البداية افتراضية للتجربة ويمكن استبدالها من ملف JSON.
- إحصائيات اللاعب التفصيلية تُقرأ من الحقول `goals`, `assists`, `cleanSheets`, `yellowCards`, `redCards`.
- نتائج الترتيب محسوبة من المباريات ذات الحالة `finished` والنتائج المسجلة.

LEAGUE APP — مدير الدوري الرياضي
================================

التشغيل السريع
1) فك ضغط league-app.zip مع الحفاظ على المجلدات.
2) افتح index.html في Chrome أو Firefox. الواجهة والبيانات الأساسية تعمل محلياً دون مكتبات أو CDN.
3) التنقل أسفل الشاشة. لوحة الإدارة في وضع العرض افتراضياً؛ رمز PIN الأولي 1234. غيّره من الإدارة > قواعد البطولة.
4) من الإعدادات يمكنك استيراد sample-league.json أو تصدير نسخة احتياطية كاملة.
5) PDF: استخدم زر طباعة التقرير/حفظ PDF من المتصفح (لا توجد مكتبة PDF خارجية).

PWA / دون اتصال
- فتح index.html مباشرة يسمح بالعمل الأساسي المحلي. المتصفحات لا تتيح Service Worker أو التثبيت عند file://.
- لتفعيل التثبيت والعمل دون اتصال، قدّم المجلد عبر localhost أو HTTPS. على Android يمكن استخدام خادم ملفات محلي بسيط من Termux ثم فتح localhost في Chrome.
- لا توجد مزامنة سحابية أو نتائج مباشرة؛ البيانات تبقى على الجهاز.

التخزين والنسخ الاحتياطي
- LocalStorage للبيانات والإعدادات وسجل التعديلات، وIndexedDB لنسخة احتياطية إضافية عند دعم المتصفح.
- صدّر JSON دورياً. حذف بيانات المتصفح قد يحذف البيانات المحلية.
- رمز PIN محلي لحماية واجهة الإدارة فقط وليس تشفيراً أمنياً للبيانات.

الملفات
index.html / style.css / core.js / engines.js / ui.js / pages.js / admin.js / app.js: ملفات تشغيل الواجهة.
css/ وjs/: نسخة هيكلية منظمة بحسب تقسيم المشروع.
data/: بيانات المثال ومخطط JSON.
manifest.json / sw.js: PWA.


إصدار League Arena 3D
---------------------
- تمت إضافة واجهة ملعب ثلاثية الأبعاد مبنية بتأثيرات CSS خفيفة دون مكتبات خارجية.
- تم ربط الأزرار بصفحات المباريات والترتيب الموجودة.
- تعرض الإحصاءات أعداد الفرق والمباريات والأهداف من بيانات التطبيق المحلية.
- تمت إضافة دعم حركة المؤشر على الشاشات المناسبة، مع احترام إعداد تقليل الحركة.
- تم تحديث اسم التطبيق وألوان PWA وإصدار ذاكرة التخزين المؤقت.
- يفضل تشغيله عبر HTTPS أو خادم محلي لتفعيل Service Worker وميزات PWA.

# وِرد — قارئ EPUB
قارئ كتب يعمل محلياً في المتصفح باستخدام HTML وCSS وJavaScript وIndexedDB.

## التشغيل
1. فك ضغط المجلد.
2. افتح `index.html` في متصفح حديث (يفضل Chrome/Edge).
3. اضغط «استيراد كتاب» واختر ملف EPUB.
4. بيانات المكتبة وموضع القراءة والعلامات والملاحظات تحفظ على الجهاز.

## الملفات
- `index.html`: بنية الواجهة.
- `style.css`: التصميم المتجاوب والمظهران الفاتح والداكن.
- `app.js`: قراءة بنية EPUB، فك ZIP، الفهرس، التخزين والتفاعل.
- `manifest.json`: بيانات تعريف قابلة للتثبيت عند تقديم المشروع عبر HTTPS أو localhost.

## ملاحظات التوافق
- يعتمد فك الضغط على واجهة `DecompressionStream('deflate-raw')` المتاحة في المتصفحات الحديثة. قد تختلف إمكانية فتح الملفات مباشرة عبر `file://` بين المتصفحات؛ إذا تعذر التخزين أو فك الضغط، افتح المجلد عبر خادم ملفات محلي موثوق.
- لا تُرفع الكتب إلى أي خادم. التخزين محلي داخل IndexedDB وقد تمسحه إعدادات المتصفح أو عند حذف بيانات الموقع.
- الفصول تُعرض عند الطلب من المحتوى المستورد، لكن نسخة المشروع الحالية تحتفظ بملفات فصول الكتاب داخل سجل IndexedDB؛ لذلك قد تستهلك الكتب الكبيرة مساحة ملحوظة.
- هذا إصدار أساس متقدم قابل للتطوير، وليس محرك EPUB كاملاً: تنسيقات CSS المعقدة، الخطوط المضمنة، الصور والموارد المرتبطة، بعض صيغ الفهرسة/التشفير ومواضع CFI لا تغطى بالكامل. كما أن تصدير المكتبة يصدر بياناتها الوصفية والعلامات والملاحظات دون ملفات EPUB نفسها.

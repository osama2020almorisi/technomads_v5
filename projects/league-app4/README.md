# دوري النخبة — تطبيق إدارة الدوري (MPA)

تطبيق ويب متعدد الصفحات (Multi-Page Application) لإدارة دوري كرة قدم كامل، مكتوب بـ HTML + CSS + JavaScript خالص بدون أي مكتبات خارجية أو CDN. يدعم العربية (RTL) والإنجليزية (LTR)، الوضع الليلي والنهاري، ويعمل دون اتصال كتطبيق PWA.

## التشغيل

### الطريقة 1: فتح مباشر
افتح الملف `index.html` بالمتصفح مباشرة (نقر مزدوج). تعمل كل الشاشات، وتُبنى البيانات التجريبية تلقائياً.
ملاحظة: ميزات PWA (التثبيت والعمل دون اتصال عبر Service Worker) تتطلب تشغيل التطبيق عبر خادم.

### الطريقة 2: خادم محلي (موصى بها)
```bash
cd league-app
python3 -m http.server 8080
```
ثم افتح: `http://localhost:8080`

أو باستخدام Node:
```bash
npx serve league-app
```

## الصلاحيات
- الوضع الافتراضي: مشاهد (عرض فقط).
- وضع الإدارة: من صفحة "الإدارة" أو "الإعدادات" أدخل رمز PIN الافتراضي: **1234**
- يمكن تغيير الرمز من الإعدادات بعد تسجيل الدخول.
- كل تعديل يُسجَّل في سجل التدقيق (Audit Log)، والحذف يتطلب تأكيداً مزدوجاً.

## اللمسات ثلاثية الأبعاد (الإصدار 1.1)
- كرة قدم ثلاثية الأبعاد مرسومة على Canvas في الصفحة الرئيسية وشاشة البداية، تدور تلقائياً ويمكن سحبها بالإصبع أو الفأرة.
- ملعب التشكيلة بمنظور ثلاثي الأبعاد مع زر تبديل 2D / 3D (يُحفظ الاختيار).
- بطاقة لاعب ثلاثية الأبعاد تنقلب عند الضغط: الوجه الأمامي للتقييم العام والإحصائيات، والخلفي للبيانات الشخصية. تفتح من التشكيلة والبدلاء والتقييمات وقائمة اللاعبين والإحصائيات.
- منصة تتويج ثلاثية الأبعاد لأول ثلاثة فرق أعلى جدول الترتيب.
- إمالة ثلاثية الأبعاد مع لمعان للبطاقات عند تحريك الفأرة على الكمبيوتر.
- قلب رقمي للنتيجة واحتفال بقصاصات ملونة عند تسجيل هدف.
- تحترم كل الحركات إعداد "تقليل الحركة" في الجهاز.

## تصدير المباريات
من زر "تصدير" في صفحة المباراة أو في لوحة الإدارة (البث المباشر):
- بطاقة صورة PNG احترافية بثلاثة مقاسات (منشور 4:5، ستوري 9:16، مربع 1:1) وثلاثة طوابع (زمردي، ليلي، ذهبي)، مع زر مشاركة مباشر على الجوال.
- تقرير PDF للمباراة: النتيجة، رجل المباراة، جدول الأحداث، الإحصائيات، التشكيلتان مع التقييمات، تصويت الجمهور.
- ملخص نصي جاهز للنسخ أو المشاركة في تطبيقات المراسلة.
- أحداث المباراة CSV، وبيانات JSON كاملة، وملف تقويم ICS مع تذكير قبل ساعة.

من زر "تصدير" في صفحة المباريات:
- بطاقة صورة لنتائج الجولة كاملة، وتقرير PDF للجولة.
- جدول المباريات CSV، وكل الأحداث CSV، والمباريات القادمة كملف تقويم ICS.

ملاحظة: ملفات PDF تُنشأ من نافذة الطباعة في المتصفح، اختر "حفظ كـ PDF".

## المحركات
- **الترتيب**: لعب/فوز/تعادل/خسارة/له/عليه/الفارق/النقاط/اللعب النظيف، مع احتساب المباريات المباشرة وخصم النقاط.
- **كسر التعادل**: يطبَّق فقط على الفرق المتساوية، مع جدول مصغّر للمواجهات المباشرة عند تعادل أكثر من فريقين. الترتيب الافتراضي: النقاط ← المواجهات ← فارق المواجهات ← أهداف المواجهات ← الفارق العام ← الأهداف ← الانتصارات ← اللعب النظيف ← القرعة. قابل لإعادة الترتيب.
- **الانضباط**: تسجيل ← عدّ ← إيقاف ← قرارات يدوية ← تصفير. الإنذار الثاني = طرد تلقائي. لا يُطبَّق إيقاف التراكم إذا صُفِّر الرصيد في الجولة نفسها.
- **التقييمات**: 1–10 تلقائية أو يدوية، تصويت الجمهور، فريق الأسبوع، لاعب الموسم.
- **الجدولة**: Round Robin (ذهاب/إياب)، توزيع الملاعب، كشف التعارضات.
- **التحقق**: رسائل أخطاء واضحة عند استيراد ملف JSON.

## البيانات
- تُحفظ في LocalStorage (المفتاح `league.data.v1`) مع نسخ احتياطية في IndexedDB.
- صيغة ملف الاستيراد موصوفة في `data/schema.json`، ومثال كامل في `data/sample-league.json`.
- التصدير: JSON كامل، وتقرير PDF عبر نافذة الطباعة (اختر "حفظ كـ PDF").
